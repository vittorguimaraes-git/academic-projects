## 📚 Projects

### ✅ To-do List

A terminal-based task manager with priorities and optional due dates. Tasks can be listed by status or searched by keyword, and overdue tasks are highlighted.

**Features**

- Create tasks with high, medium, or low priority
- Optionally set a due date
- View all tasks, completed tasks, or pending tasks
- Search tasks by keyword
- Mark tasks complete, edit them, or delete them
- Store tasks locally as JSON

## 🛠️ Run it

Requires Python 3.14 or later.

```sh
git clone https://github.com/vittorguimaraes-git/projects.git
cd projects
python -m src.todo_list.todo_list
```

Choose an option from the menu and follow the prompts. Task data is saved to `tasks.json` in the directory where you run the command.
